# 4. Что такое Vite?

## 4.1. Зачем нужен Vite?

До сих пор для небольших проектов мы могли просто создать файлы:

```
index.html
style.css
app.js
```

И открыть `index.html` в браузере.

Но React-проект сложнее.

Он использует:

- JavaScript-модули.
- JSX.
- Сторонние библиотеки.
- Систему импортов.
- Автоматическую сборку файлов.

Нам нужен инструмент, который подготовит проект и поможет его запускать.

Таким инструментом будет Vite (произносится «вит»).

Vite — инструмент разработки и сборки современных frontend-приложений.

Он помогает создать проект, запустить локальный сервер и быстро увидеть изменения в браузере.

## 4.2. Чем отличаются React, Vite, Node.js и WebStorm?

| Инструмент | Для чего нужен                                                            |
| ---------- | ------------------------------------------------------------------------- |
| JavaScript | Язык программирования                                                     |
| React      | Создание интерфейса                                                       |
| Vite       | Создание, запуск и сборка проекта                                         |
| Node.js    | Выполнение JavaScript вне браузера; необходим для инструментов разработки |
| npm        | Установка библиотек и запуск скриптов                                     |
| WebStorm   | Среда, в которой пишем и отлаживаем код                                   |
| Браузер    | Показывает готовый интерфейс                                              |

Очень важно: Vite не заменяет React.

React создаёт интерфейс. Vite помогает нам разрабатывать и запускать приложение.
