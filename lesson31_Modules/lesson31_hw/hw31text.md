# HW_31_TEXT



## Задание: Mini Calculator

Создайте небольшое приложение — калькулятор, состоящий из нескольких JavaScript-файлов.

Все вычисления должны выполняться в отдельных модулях, а результаты выводиться в консоль браузера.

### 1. Структура проекта

Создайте проект со следующей структурой:

```
HW_Modules/
│
├── index.html
│
├── css/
│   └── style.css
│
└── js/
    ├── app.js
    ├── math.js
    └── geometry.js
```

В `index.html` подключите только один JavaScript-файл — `app.js`, используя `type="module"`.

Остальные JavaScript-файлы должны подключаться через `import`.

### 2. Модуль math.js

Создайте и экспортируйте четыре функции:

| Функция          | Назначение                   |
| ---------------- | ---------------------------- |
| `add(a, b)`      | Возвращает сумму двух чисел  |
| `subtract(a, b)` | Возвращает разность          |
| `multiply(a, b)` | Возвращает произведение      |
| `divide(a, b)`   | Возвращает результат деления |

**Дополнительное условие:** если второй аргумент функции `divide()` равен нулю, функция должна вернуть строку `"Cannot divide by zero"`.

Используйте именованные экспорты (`named exports`).

### 3. Модуль geometry.js

Создайте и экспортируйте:

- Константу `PI` со значением `3.14159`.
- Функцию `getCircleArea(radius)`, вычисляющую площадь круга по формуле `PI * radius * radius`.
- Функцию `getRectangleArea(width, height)`, вычисляющую площадь прямоугольника.
- Функцию `getCircleLength(radius)`, вычисляющую длину окружности по формуле `2 * PI * radius`.

Все функции должны возвращать результат через `return`.

### 4. Основной файл app.js

Импортируйте необходимые функции и константу из двух модулей.

Выполните следующие вычисления:

**Математические операции:**

```
15 + 7
20 - 8
6 * 9
100 / 4
10 / 0
```

**Геометрические вычисления:**

```
Площадь круга с радиусом 5
Площадь прямоугольника со сторонами 8 и 12
Длина окружности с радиусом 10
```

Результаты выведите в консоль с понятными подписями.

Пример:

```
15 + 7 = 22
20 - 8 = 12
6 * 9 = 54
100 / 4 = 25
10 / 0 = Cannot divide by zero

Circle area (r=5): 78.53975
Rectangle area (8x12): 96
Circle length (r=10): 62.8318
```

 
## Требования к выполнению

- Использовать ES Modules.
- В HTML подключать только `app.js`.
- Использовать `export` и `import` для связи файлов.
- Все вычисления выполнять в соответствующих модулях.
- Все результаты выводить через `console.log()`.
- Не использовать `default export`.
- Не использовать сторонние библиотеки.

**Запуск:** через локальный сервер WebStorm, открывая `index.html`  
**Результат:** работающий проект с тремя JavaScript-файлами, в котором `app.js` управляет вычислениями, а `math.js` и `geometry.js` предоставляют необходимые функции.
