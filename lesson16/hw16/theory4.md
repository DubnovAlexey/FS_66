## 📘 Conditions

В этом конспекте ты познакомишься с условиями — механизмом, который позволяет программе принимать решения и изменять своё поведение.

---

# 🧠 1. Что такое условия

**Условия (conditions)** — это конструкции, которые позволяют выполнять разные действия в зависимости от ситуации.

📌 Проще говоря:
условие — это «если что-то верно → сделать действие».

---

## 📦 Пример из жизни:

* если идёт дождь → взять зонт
* если нет → не брать

---

👉 В программировании — то же самое.

---

# 🎯 2. Зачем нужны условия

Условия позволяют:

* управлять логикой программы
* принимать решения
* обрабатывать разные сценарии

---

👉 Без условий программа выполнялась бы всегда одинаково.

---

# 🔍 3. Операторы сравнения

Перед тем как писать условия, нужно понимать сравнения.

---

## 📦 Основные операторы:

```javascript
==   // равно (без строгой проверки типа)
===  // строго равно
!=   // не равно
!==  // строго не равно
>    // больше
<    // меньше
>=   // больше или равно
<=   // меньше или равно
```

---

## 📦 Пример:

```javascript
let age = 18;

console.log(age >= 18); // true
```

---

👉 Результат — это boolean (true / false)

---

# 🔹 4. Одиночный if

**if** — это базовое условие.

---

## 📌 Синтаксис:

```javascript
if (условие) {
  действие
}
```

---

## 📦 Пример:

```javascript
let age = 20;

if (age >= 18) {
  console.log("Access allowed");
}
```

---

## 🧠 Как работает:

* если условие true → выполняется код
* если false → ничего не происходит

---

👉 Используется, когда нужно выполнить действие **только при выполнении условия**.

---

# 🔀 5. if-else

**if-else** — позволяет выбрать между двумя вариантами.

---

## 📌 Синтаксис:

```javascript
if (условие) {
  действие1
} else {
  действие2
}
```

---

## 📦 Пример:

```javascript
let age = 16;

if (age >= 18) {
  console.log("Access allowed");
} else {
  console.log("Access denied");
}
```

---

## 🧠 Как работает:

* true → выполняется if
* false → выполняется else

---

👉 Используется, когда есть **два варианта поведения**.

---

# 🪜 6. if-else ladder (цепочка условий)

Это последовательность нескольких условий.

---

## 📌 Синтаксис:

```javascript
if (условие1) {
  действие1
} else if (условие2) {
  действие2
} else {
  действие3
}
```

---

## 📦 Пример:

```javascript
let score = 75;

if (score >= 90) {
  console.log("Excellent");
} else if (score >= 70) {
  console.log("Good");
} else if (score >= 50) {
  console.log("Pass");
} else {
  console.log("Fail");
}
```

---

## 🧠 Как работает:

* проверяется первое условие
* если false → следующее
* выполняется только **один блок**

---

👉 Используется, когда есть **несколько вариантов**.

---

# 🔗 7. Логические операторы

Позволяют комбинировать условия.

---

## 📦 Основные:

```javascript
&&  // И (оба условия должны быть true)
||  // ИЛИ (хотя бы одно true)
!   // НЕ (инверсия)
```

---

## 📦 Пример:

```javascript
let age = 20;
let hasTicket = true;

if (age >= 18 && hasTicket) {
  console.log("Access allowed");
}
```

---

👉 Важно:
можно строить более сложные проверки.

---

# 🧪 8. Практический пример

```javascript
let productPrice = 100;
let quantity = 3;

let total = productPrice * quantity;

if (total > 200) {
  console.log("Discount applied");
} else {
  console.log("No discount");
}
```

---

# 🐞 9. Использование дебаггера

В Visual Studio Code можно:

---

## 📌 Отслеживать:

* значение условий
* какие ветки выполняются
* значения переменных

---

## 🧠 Пример:

```javascript
let age = 17;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}
```

---

## 📊 В дебаггере:

```text
age → 17
age >= 18 → false
```

---

👉 Видно, почему выполняется ветка else.

---

# ⚠️ 10. Частые ошибки

## ❌ Использование = вместо == или ===

```javascript
if (age = 18) // ошибка
```

---

## ❌ Неправильная логика условий

→ условия перекрывают друг друга

---

## ❌ Отсутствие else

→ не обработаны все случаи

---

## ❌ Сложные условия без структуры

→ трудно понять и отладить

---

# 🧠 Важные выводы

* условия позволяют программе принимать решения
* if — для одного сценария
* if-else — для двух вариантов
* if-else ladder — для нескольких вариантов
* логические операторы помогают усложнять условия
* дебаггер помогает понять, как работает логика
