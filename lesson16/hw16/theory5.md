## 📘 Arrays

В этом конспекте ты познакомишься с массивами — структурой данных, которая позволяет хранить несколько значений в одной переменной и удобно с ними работать.

---

# 🧠 1. Что такое массив

**Массив (array)** — это структура данных, которая хранит список значений.

📌 Проще говоря:
массив — это «список элементов в одной переменной».

---

## 📦 Пример:

```javascript
let numbers = [10, 20, 30];
```

---

## 📌 Что здесь происходит:

* `numbers` — переменная
* `[]` — массив
* `10, 20, 30` — элементы массива

---

👉 Важно:
Все элементы хранятся в **определённом порядке**.

---

# 🎯 2. Зачем нужны массивы

Массивы используются, когда нужно:

* хранить несколько значений
* работать со списками
* обрабатывать данные группами

---

## 📦 Пример без массива:

```javascript
let item1 = "Apple";
let item2 = "Banana";
let item3 = "Orange";
```

---

## 📦 С массивом:

```javascript
let fruits = ["Apple", "Banana", "Orange"];
```

---

👉 Массив делает код проще и удобнее.

---

# 🧱 3. Внутренняя структура массива

Каждый элемент массива имеет **индекс** — позицию.

📌 Индексация начинается с **0**.

---

## 📊 Пример:

```javascript
let fruits = ["Apple", "Banana", "Orange"];
```

```text
Индекс:   0        1         2
Значение: Apple  Banana   Orange
```

---

👉 Важно:

* первый элемент — индекс 0
* доступ к элементам идёт по индексу

---

# 🔧 4. Работа с массивами (CRUD)

---

## 🔹 4.1 Создание (Create)

```javascript
let numbers = [1, 2, 3];
```

---

---

## 🔹 4.2 Чтение (Read)

```javascript
console.log(numbers[0]); // 1
console.log(numbers[1]); // 2
```

---

👉 Используется `[]` и индекс.

---

---

## 🔹 4.3 Обновление (Update)

```javascript
numbers[1] = 20;
```

---

👉 Теперь массив:

```javascript
[1, 20, 3]
```

---

---

## 🔹 4.4 Добавление элементов

```javascript
numbers.push(4);
```

---

👉 Результат:

```javascript
[1, 20, 3, 4]
```

---

---

## 🔹 4.5 Удаление элементов

```javascript
numbers.pop();
```

---

👉 Удаляет последний элемент:

```javascript
[1, 20, 3]
```

---

---

## 🔹 4.6 Удаление по индексу (базово)

```javascript
numbers.splice(1, 1);
```

---

👉 Удаляет элемент с индексом 1.

---

# 🧪 5. Практический пример

```javascript
let cart = ["Phone", "Laptop"];

cart.push("Tablet");        // добавили товар
cart[0] = "Smartphone";     // обновили первый элемент

console.log(cart);

cart.pop();                 // удалили последний элемент

console.log(cart);
```

---

## 📊 Возможный результат:

```javascript
["Smartphone", "Laptop", "Tablet"]
["Smartphone", "Laptop"]
```

---

# ⚠️ 7. Частые ошибки

## ❌ Обращение к несуществующему индексу

```javascript
console.log(numbers[10]); // undefined
```

---

## ❌ Забыли, что индекс начинается с 0

---

## ❌ Ошибки при удалении

```javascript
numbers.splice(5, 1); // индекс может не существовать
```

---

## ❌ Неожиданное изменение массива

→ массив изменяется напрямую (это нормально, но важно понимать)

---

# 🧠 Важные выводы

* массив — это список значений
* элементы имеют индексы (с 0)
* можно выполнять:

  * создание
  * чтение
  * обновление
  * добавление
  * удаление
* массивы упрощают работу с группами данных
* дебаггер помогает видеть изменения
