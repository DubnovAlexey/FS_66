## 📘 Loops

В этом конспекте ты познакомишься с циклами — конструкциями, которые позволяют выполнять одни и те же действия несколько раз.

---

# 🧠 1. Что такое цикл

**Цикл (loop)** — это конструкция, которая повторяет выполнение кода несколько раз.

📌 Проще говоря:
цикл — это «сделай одно и то же действие много раз».

---

## 📦 Пример из жизни:

* вывести список товаров
* посчитать сумму чисел
* обработать все элементы массива

---

👉 Важно:
без циклов пришлось бы писать один и тот же код много раз.

---

# 🎯 2. Зачем нужны циклы

Циклы используются, когда нужно:

* повторять действия
* обрабатывать списки данных
* автоматизировать однотипные операции

---

## 📦 Пример без цикла:

```javascript id="noLoop"
console.log("Hello");
console.log("Hello");
console.log("Hello");
```

---

## 📦 С циклом:

```javascript id="withLoop"
for (let i = 0; i < 3; i++) {
  console.log("Hello");
}
```

---

👉 Код стал короче и удобнее.

---

# 🔁 3. Основные виды циклов в JavaScript

---

# 🔹 3.1 for

Самый универсальный цикл.

---

## 📌 Синтаксис:

```javascript id="forSyntax"
for (инициализация; условие; изменение) {
  код
}
```

---

## 📦 Пример:

```javascript id="forExample"
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

---

## 🧠 Как работает:

1. создаётся переменная `i`
2. проверяется условие
3. выполняется код
4. `i` изменяется
5. повтор

---

👉 Используется, когда:

* известно количество повторений
* нужен контроль над индексом

---

# 🔹 3.2 while

Цикл с условием.

---

## 📌 Синтаксис:

```javascript id="whileSyntax"
while (условие) {
  код
}
```

---

## 📦 Пример:

```javascript id="whileExample"
let i = 0;

while (i < 5) {
  console.log(i);
  i++;
}
```

---

👉 Используется, когда:

* неизвестно точное количество повторений
* важно условие остановки

---

---

# 🔹 3.3 do...while

Похож на while, но выполняется хотя бы один раз.

---

## 📌 Синтаксис:

```javascript id="doWhileSyntax"
do {
  код
} while (условие);
```

---

## 📦 Пример:

```javascript id="doWhileExample"
let i = 0;

do {
  console.log(i);
  i++;
} while (i < 5);
```

---

👉 Важно:
код выполнится **минимум один раз**.

---

# 🔹 3.4 for...of (базово)

Используется для перебора массивов.

---

## 📦 Пример:

```javascript id="forOfExample"
let fruits = ["Apple", "Banana", "Orange"];

for (let fruit of fruits) {
  console.log(fruit);
}
```

---

👉 Используется, когда:

* нужно пройти по всем элементам массива
* не нужен индекс

---

# ⚖️ 4. Как выбрать цикл

---

## 🧠 Рекомендации:

* **for** → когда нужен индекс или известно количество
* **while** → когда цикл зависит от условия
* **do...while** → когда нужно выполнить хотя бы один раз
* **for...of** → для простого перебора массива

---

---

# 🧪 5. Работа с массивами

---

## 📦 Пример:

```javascript id="arrayLoop"
let prices = [100, 200, 300];

let total = 0;

for (let i = 0; i < prices.length; i++) {
  total = total + prices[i];
}

console.log("Total: " + total);
```

---

👉 Цикл позволяет обработать все элементы.

---

---

## 📦 Альтернатива:

```javascript id="arrayLoop2"
let prices = [100, 200, 300];

let total = 0;

for (let price of prices) {
  total = total + price;
}
```

---

👉 Более простой вариант.

# ⚠️ 7. Частые ошибки

## ❌ Бесконечный цикл

```javascript id="infLoop"
while (true) {
}
```

---

👉 программа зависает

---

---

## ❌ Забыли изменить переменную

```javascript id="infLoop2"
let i = 0;

while (i < 5) {
  console.log(i);
}
```

---

👉 `i` не изменяется → бесконечный цикл

---

---

## ❌ Ошибка в условии

```javascript id="wrongCond"
for (let i = 0; i <= 5; i++)
```

👉 может выйти за пределы массива

---

---

## ❌ Неправильный выбор цикла

→ усложняет код

# 🧠 Важные выводы

* цикл — это способ повторять действия
* основные виды:

  * for
  * while
  * do...while
  * for...of
* циклы нужны для работы с данными и массивами
* важно правильно выбрать тип цикла
* дебаггер помогает понять выполнение
