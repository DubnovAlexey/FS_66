# User Registration

Учебное приложение регистрации пользователей на HTML, CSS и JavaScript без сборки и сторонних библиотек.

## Запуск

Откройте `index.html` в современном браузере. Установка пакетов или запуск сервера не нужны. Данные хранятся в памяти вкладки и исчезают после её перезагрузки.

## Возможности

- проверка имени и возраста с выводом ошибок на страницу и в Console;
- уникальный числовой `id` для каждого пользователя в текущем запуске;
- закрытое хранилище на замыкании;
- общий счётчик, удаление записей и фильтр совершеннолетних;
- адаптивный интерфейс в спокойной деловой палитре;
- комментарии на русском языке к строкам исходного кода.

Полное объяснение для читателя с нуля находится в [THEORY_RU.md](THEORY_RU.md).
