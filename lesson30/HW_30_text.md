🏠 HW_15 — Error Handling
Используйте API:

https://jsonplaceholder.typicode.com/users

Необходимо получить список пользователей и обработать возможные ошибки при загрузке и проверке данных.

Задание
С помощью axios получите массив пользователей.

Создайте функцию:

function validateUser(user) {
// ваш код
}
Функция должна проверить пользователя.

Пользователь считается корректным, если:

существует name;
существует email;
id является числом.
Если какое-либо условие не выполняется, необходимо самостоятельно создать ошибку с помощью:

throw new Error(...)
Например:

throw new Error("User name is missing");
После получения данных от API переберите всех пользователей и вызовите для каждого:
validateUser(user);
Если пользователь корректный, выведите в консоль:

User is valid: Leanne Graham
Если при проверке пользователя возникла ошибка, программа не должна завершаться. Перехватите ошибку с помощью try...catch и выведите:

Validation error: User name is missing
Отдельно обработайте ошибку самого HTTP-запроса.
Если данные получить не удалось, программа должна вывести:

API error
Для обработки ошибки запроса используйте .catch().

Нужно различить два типа проблем: ошибка получения данных от API и ошибка валидации уже полученных данных.
⭐ Дополнительное задание
После того как основной вариант заработал, специально испортите одного пользователя перед проверкой:

users[0].email = null;
Проверьте, что программа:

обнаружила ошибку;
вывела понятное сообщение;
не остановилась;
продолжила проверять остальных пользователей.
Важно: catch не должен быть пустым — сообщение об ошибке необходимо вывести в консоль.
